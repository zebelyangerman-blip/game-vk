# Сад самоцветов — Lumina R18.3 (VK/OK Cloud Safety)

## Исправления R18.3
- Экономика больше не выбирается по количеству пройденных уровней. Новые награды, покупки и расход усилителей записываются в журнал отдельных операций с уникальными идентификаторами.
- При объединении двух устройств повторные награды за первый выигрыш уровня и за один и тот же день учитываются только один раз.
- Два независимых офлайн-изменения объединяются детерминированно; при нехватке средств или предметов на конфликтующие покупки сохраняется предупреждение, а монеты не становятся отрицательными. Не требуется обнуление прогресса.
- Для старых сохранений R18.2 без журнала применяется последняя по времени экономическая версия, а не «больше достижений». После первого старта создаётся новый журнал.
- Перед облачной записью повторно читается актуальное сохранение, сохраняются два восстановимых слота. Добавлены повторные попытки после сетевой ошибки и синхронизация при возвращении в приложение.
- При скрытии приложения инициируется немедленная запись (в первую очередь локальная) и асинхронная выгрузка в облако.
- Область нажатия настроек в мобильном портрете не меньше 44×44 CSS px.
- Основная графика самоцветов, R18.2 мобильный режим лёгких эффектов, уровни, 36 уроков и 100 заданий усадьбы не переделывались.

### Ограничение облака
VK Bridge StorageGet/StorageSet не предоставляет клиенту транзакционную compare-and-swap-запись. Последние доли секунды при двух одновременных записях невозможно гарантировать без серверного координирования. Обновление сокращает риск конфликтов и делает восстановление прозрачнее, но требует проверки на настоящих VK и OK аккаунтах.

# Сад самоцветов — R18.2 «VK Sync & Mobile Performance»

**Полная готовая сборка** на базе R18.1, предназначенная для тестирования в VK Mini Apps. Файлы лежат в корне архива: `index.html`, `assets/`, `README_RELEASE_RU.md`, `THIRD_PARTY_NOTICES.txt`. **Сохраните резервную копию R18.1** перед заменой файлов на GitHub.

## Две главные технические правки для модерации

### 1) Межплатформенное сохранение VK

- До первого активного игрового экрана выполняется `VKWebAppStorageGet`. Затем локальный и облачный прогресс согласуются: пройденные уровни, звёзды, рекорды, уникальные награды за первые победы и восстановленные объекты усадьбы не теряются. Монеты и усилители берутся из одного согласованного снимка, а не складываются дважды.
- `VKWebAppStorageSet` сохраняет UTF-8 прогресс небольшими ASCII-частями, **не более 3000 символов на один ключ**. Две независимые чередующиеся копии и контрольные суммы снижают риск потери данных при обрыве связи. Данные проявляются как успешная версия только после записи итоговой контрольной записи.
- Сохраняется прежний ключ `gemGardenV14Progress`, старые сохранения R18.1 совместимы; для legacy-облака читается старый ключ `gem_garden_v14_backup`.
- На старте внутри VK игрок видит короткое состояние «Восстанавливаем прогресс», а в настройках — статус облака. Если VK временно не отвечает, игра остаётся доступна с локальным прогрессом, а опасная перезапись повреждённого облака блокируется.
- Для корректной записи необходимы работающие `VKWebAppStorageGet` и `VKWebAppStorageSet` **из одного и того же приложения VK и аккаунта** на всех целевых устройствах. Локально эта схема проверена имитацией ответов VK Bridge; проверка на двух реальных устройствах VK обязательна.

### 2) Оптимизация mobile web

- На телефонах при параметре качества «Автоматически» включается **низкая стоимость эффектов**, без размытия и понижения разрешения оригинальных самоцветов.
- Для низкого уровня ограничение частиц Canvas снижено с 120 (бывший средний мобильный режим R18.1) до 24. Отдельно уменьшено число вспомогательных DOM-частиц и масштаб внутреннего рендера Canvas; длительность самих эффектов остаётся заметной.
- При пропуске кадров анимационный план корректно догоняет реальное время, вместо искусственного замедления. Десктоп «Автоматически» выбирает высокое качество при достаточных ресурсах.
- Выбор «Высокое / Среднее / Низкое» остаётся в настройках; это устройство-зависимая настройка, она больше не переносится из облака с компьютера на телефон.

## Проверки этой сборки

- VK Bridge: запись, чтение на условном втором устройстве, unicode и многоключевое сохранение 100/100 уровней и 100/100 строительных работ, merge, offline, legacy, оборванная запись и повреждённый слот — проверки через браузерный mock.
- Синтетический тест на Chromium с замедлением CPU 4×: R18.1 — 26 кадров с интервалом более 40 мс; R18.2 — 1 такой кадр в одном одинаковом сценарии. Это **не FPS реального iPhone**.
- Сцены: 10 зон на 6 форматах (60 проверок), уровни на 6 форматах (150 конфигураций, включая все 100 на самом узком экране), без горизонтальных переполнений и JS-ошибок. Режим телефона — **только portrait**, с учётом короткого окна и iPhone safe area. Десктоп — не widescreen, контрольные 1000×1150 и 1150×900.
- Учебная программа 36 шагов, сочетания бонусов и все 100 игровых уровней ранее отдельно пройдены в R18.1; их правила в R18.2 не менялись. Это не новый полный прогон побед 100/100 в R18.2.
- JS синтаксис, HTML ресурсы, ZIP и декодирование изображений проверяются при упаковке.

## Что нельзя подтвердить локально

1. **Полное соответствие каждому пункту действующих правил VK Mini Apps:** страницу `https://dev.vk.com/ru/mini-apps-rules` не удалось получить целиком через веб-доступ. Проверены подтверждённые замечания модератора, код приложения и доступные документы Bridge; нормативная построчная проверка остаётся открытой.
2. Восстановление между реальными Android/iOS/mobile web/desktop под одной учётной записью VK, а также доступность внешнего CDN VK Bridge в регионе игрока: необходим тест после тестового размещения.
3. Фактический FPS и отсутствие торможений **в WebView на физическом iPhone и Android**. Синтетический Chromium только показывает снижение нагрузки.
4. Настройки самих карточек приложения, возрастной рейтинг, разрешения, описания, обложки и юридические требования страницы кабинета VK — не содержатся в ZIP и проверяются в кабинете.

**Публикация:** распакуйте содержимое прямо в корень репозитория, обновите Pages и проверьте внутри VK на iPhone, Android, Mobile Web и Desktop с одним и тем же VK аккаунтом. Убедитесь, что выигранный уровень/постройка отображается на другом устройстве после перезапуска, а анимации не подтормаживают на слабом устройстве. Только после этого повторно отправляйте на модерацию.

## История версии R18.1 (унаследована)


Это **полный архив игры**, собранный на проверенной R18. Остальные игровые системы и усадьба не переписывались.

## Новое в R18.1

- **Квадрат 2×2 одинаковых самоцветов, созданный обменом → бомба.** Одиночная бомба поражает 3×3; две бомбы — 5×5.
- **Т- или L-образное пересечение одинаковых самоцветов → Светлячок.** Ранее квадрат создавал Светлячка, а T/L — бомбу; теперь эти правила поменялись местами.
- Правила 4 в ряд → ракета и 5 по прямой → радужный шар сохранены. Эффекты и совместные действия бонусов сохранены.
- Начальный курс расширен до **36 интерактивных шагов**: создание и запуск всех бонусов, обе ориентации ракет, Т и L для Светлячка, **15 пар специальных бонусов** плюс радуга с обычным самоцветом, препятствия и молоток. Каждое действие игрок выполняет на настоящем учебном поле с игровыми анимациями.
- Раздел «Правила» обновлён. Сохранения R18 не сбрасываются; незавершённый курс старой версии обучения перезапускается с первого нового шага. Уже завершённое обучение можно повторить из настроек. Курс можно пропустить.

## Настройки экрана

Телефоны: **только книжная ориентация**; iPhone safe area и элементы VK над окном. Десктоп: **без широкоформатного режима**, целевой iframe 1000–1150 пикселей. На коротких книжных экранах допускается вертикальная прокрутка, но не горизонтальная.

## Основа R18: история обновления и инструкция установки

R18 построена поверх R17 и R16. В архиве содержится **полная игра**, а не патч к предыдущей версии.

## Основные изменения R18

- На телефонах оставлена **книжная компоновка** усадьбы; игровой сад вынесен ближе к началу экрана. Текстовые подсказки и кнопка просмотра деталей теперь находятся **под сценой**, не закрывая постройки, дорожки, растения и фонтан.
- Упрощены повторяющиеся подписи. У декоративных объектов появились осмысленные названия и описания вариантов оформления вместо «Вариант 1/2».
- В парадной зоне исправлены альтернативные ворота: второй стиль теперь также является полноценными воротами, а не отдельной деталью ограды.
- На **мобильном экране игры** добавлены явно видимые кнопки «Магазин» и «Подарок» под усилителями. На десктопе сохранены старые способы доступа.
- Выделены разные цветовые настроения десяти зон без замены архитектуры общего поместья. Поведение света, воды и декоративных объектов сохранено.
- Система дома R16: **3 архитектурных стиля × 5 стадий**. Стадии определяются количеством выполненных заданий, финальная — после всех 100 работ. Выбранный стиль одинаков для всех сцен.
- В R18 были сохранены тогдашние правила бонусов, лимиты ходов, награды, платформа VK и ключ сохранений. В R18.1 изменены только способы создания бомбы и Светлячка и обучение.

## Настройки VK (важно)

- **Телефоны:** только книжная ориентация (portrait), адаптация под iPhone включена; элементы управления VK находятся над игровым окном.
- **Десктоп:** широкоформатный режим выключен; целевой iframe около 1001–1150 пикселей по ширине, включая контрольную область 1000×1150.
- Страница допускает **вертикальную прокрутку** на коротких экранах телефона. Горизонтальная прокрутка не должна возникать.

## Установка

1. Сохраните копию прежнего релиза (R18).
2. Распакуйте ZIP **в корень репозитория**. В корне должны лежать `index.html` и каталог `assets/` на одном уровне.
3. Замените соответствующие файлы и опубликуйте обновление через текущий GitHub/VK-процесс.
4. Проверьте сохранения, рекламу и SDK **непосредственно внутри VK**, а также портретный экран реального iPhone.

## Проверка

Выполнены автоматические прохождения **100 уровней** с игровыми ограничениями, **100 строительных работ** с реальными нажатиями, **16 тестов сочетаний бонусов**, 60 проверок сцен усадьбы на шести размерах экрана и расширенные браузерные регрессионные тесты игровой компоновки. Тестирование проходило в Chromium/Playwright. История проверок R18 приведена в ранее выпущенном отдельном QA-отчёте. Итоговые тесты R18.1 документируются отдельно.

**Ограничения:** тесты не доказывают субъективную идеальность баланса, не заменяют действия живых игроков, не измеряют производительность на физическом iPhone и не подтверждают работу рекламы/облачных сохранений внутри приложения VK. Все десять зон по-прежнему используют единый художественный фоновый пейзаж; индивидуальность зон усиливается композициями и локальной атмосферой, но это не десять отдельных фоновых иллюстраций.
